# 🦜 LangChain YouTube & Website Summarizer

A Streamlit app that uses **LangChain** and **Groq LLM** (Llama 3.1) to summarize content from **YouTube videos** or **websites**. Just provide a URL and your Groq API key, and the app generates a concise 300-word summary.

---

## Features

- Summarizes **YouTube video transcripts**.
- Summarizes **any website content**.
- Uses **Groq LLM** (`llama-3.1-8b-instant`) for high-quality summaries.
- Clean, easy-to-use **Streamlit interface**.
